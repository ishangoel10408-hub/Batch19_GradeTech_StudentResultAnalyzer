
# Batch19_GradeTech_StudentResultAnalyzer

## GradeTech – Student Result and Grade Analyzer

**C Programming Mini Hackathon – Batch 19**

## 1. Problem Statement
To develop a C program that accepts marks of five subjects for multiple students and calculates their total marks, percentage, grade and pass/fail status. It also identifies the class topper and calculates the class average.

## 2. Objectives
- Store student details and marks.
- Calculate total marks and percentage.
- Assign grades to students.
- Identify pass/fail status.
- Search and display student records.
- Find class topper and class average.

## 3. Features
1. Add Student
2. Display All Results
3. Search Student
4. Class Topper and Average
5. Exit

## 4. C Concepts Used
- Variables and Operators
- Conditional Statements (if-else)
- Loops (for, do-while)
- Arrays
- Strings
- Structures
- Functions
- Pointers
- Switch Case

## 5. Passing Criteria
A student must score at least 33 marks in each subject to pass.

## 6. Algorithm
1. Start the program.
2. Display the menu.
3. Accept the user's choice.
4. Add student details and five subject marks.
5. Calculate total, percentage and grade.
6. Check pass/fail status.
7. Display or search student results.
8. Calculate class topper and average.
9. Repeat the menu until Exit is selected.
10. Stop the program.

## 7. How to Compile and Run

Compile:
```bash
gcc Student_Result_Analyzer.c -o Student_Result_Analyzer
```

Run on Windows:
```bash
.\Student_Result_Analyzer.exe
```

## 8. Project Files
- `Student_Result_Analyzer.c` – Main C program.
- `.gitignore` – Excludes compiled and temporary files.
- `README.md` – Project documentation.

## 9. Conclusion
GradeTech provides a simple way to manage student results using basic C programming concepts. It calculates academic performance and displays useful class information.
