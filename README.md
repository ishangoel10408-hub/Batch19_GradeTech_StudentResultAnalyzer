# GradeTech – Student Result and Grade Analyzer

**C Programming Mini Hackathon – Batch 19**

## 1. Problem Statement

To develop a C program that accepts marks of five subjects for multiple students and calculates their total marks, percentage, grade and pass/fail status. It also identifies the class topper and calculates the class average.

## 2. Objectives

- Store student details and marks.
- Calculate total marks and percentage.
- Assign grades to students.
- Identify pass/fail status.
- Search and display student records.
- Find class topper and class average.

## 3. Features

1. Add Student
2. Display All Results
3. Search Student
4. Class Topper and Average
5. Exit

## 4. C Concepts Used

- Variables and Operators
- Conditional Statements (if-else)
- Loops (for, do-while
